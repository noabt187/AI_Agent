# Ink workspace background

`ink-landscape.png` is a locally bundled decorative asset generated with the built-in imagegen tool on 2026-09-06. No runtime image service or external font request is required.

The host CSS applies grayscale, low opacity and non-interactive positioning. Light mode uses a neutral gray-white canvas; dark mode is optional. The background must never become a text container or an interactive layer.
